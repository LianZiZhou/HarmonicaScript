HarmonicaScript - macOS

  HarmonicaScript.app       graphical interface - double-click it
  ./hsc                     command line  ("./hsc --help")

Nothing to install: the .NET runtime is included inside the bundle.

hsc is a symlink into HarmonicaScript.app/Contents/MacOS/, so keep the two together.

The build is unsigned and unnotarised, so macOS quarantines it. Clear that once, from inside
the extracted folder:

  xattr -dr com.apple.quarantine .

Note that the game itself is Windows-only. On macOS you can convert, audition and export;
the live playback backend here is a development aid, not a way to play the game.

data/ holds the instrument and timing profiles. They are plain JSON and you are MEANT to edit
them - every number describing the game is inferred rather than measured. Run
"./hsc profile dump --effective" to see where each value came from, and read docs/CALIBRATION.md.
