HarmonicaScript - macOS

  HarmonicaScript.app       graphical interface
  ./hsc                     command line  ("./hsc --help")

Nothing to install: the .NET runtime is included inside the bundle. hsc is a symlink into
HarmonicaScript.app/Contents/MacOS/, so keep the two together.


EXTRACT WITH FINDER, NOT WITH `unzip`
-------------------------------------
Double-click the .zip in Finder. Do not extract it with the command-line `unzip`.

The bundle contains .NET managed .dll files, which macOS insists are signed code but which have
nowhere inside them to store a signature - so the signature lives in an extended attribute.
Finder (and `ditto -x -k`) preserve those; `unzip` silently drops them and macOS then reports
the app as damaged. If you already used `unzip`, delete the folder and extract it again.


FIRST LAUNCH
------------
This build is ad-hoc signed but NOT notarised - notarising needs a paid Apple Developer ID.
macOS blocks the first launch of anything a browser downloaded. Either:

  Right-click (or Control-click) HarmonicaScript.app -> "Open" -> "Open". Once only.

or clear the download quarantine for the whole folder, which works however you extracted it:

  xattr -dr com.apple.quarantine .


THE GAME IS WINDOWS-ONLY
------------------------
On macOS you can convert, audition and export. The live playback backend here is a development
aid, not a way to play the game.


CONFIGURATION
-------------
data/ inside the bundle holds the instrument and timing profiles. They are plain JSON and you
are MEANT to edit them - every number describing the game is inferred rather than measured.

  ./hsc profile dump --effective     shows where each value came from

Read docs/CALIBRATION.md.
